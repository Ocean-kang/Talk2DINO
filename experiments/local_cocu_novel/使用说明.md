# Local-CoCu 额外 Concept 去重实验

## 实验目标

在原版 Local-CoCu 基础上，只新增一个干预：**先移除目标图像原始 5 条 Captions 中已有的 Concepts，再使用预训练 Talk2DINO 做 Head–Concept 匹配**，选择至多 3 个新增 Concepts，最后按原版 `train.py` 训练全新 Student。

每张图像最终训练样本为 **5 条原始 Captions + 0～3 条新增 Concept Captions**。不补齐虚假 Concepts，不修改 `src/`、`train.py` 和现有实验代码。评估使用原来四个分割数据集。

## 安装

从 Talk2DINO 根目录执行：

```bash
cd /home/master/code/oymk/Talking2dino/Talk2DINO
unzip local_cocu_novel.zip -d experiments/
```

## 推荐：重用已完成的 Local-CoCu 特征

需要有：

- `outputs/local_cocu/candidate/candidate_concepts.json`
- `outputs/local_cocu/head_features/head_features.pt`
- `outputs/coco2014_b14/train.pth` 和 `val.pth`
- `weights/vitb_mlp_infonce.pth`

一键从筛选做到训练：

```bash
bash experiments/local_cocu_novel/run.sh all 1 --reuse-local
```

想完整重新提取图像特征、做近邻检索、候选生成、去重、匹配和训练：

```bash
bash experiments/local_cocu_novel/run.sh all 1
```

分步骤：

```bash
bash experiments/local_cocu_novel/run.sh filter 1 --reuse-local
bash experiments/local_cocu_novel/run.sh match 1 --reuse-local
bash experiments/local_cocu_novel/run.sh build 1 --reuse-local
bash experiments/local_cocu_novel/run.sh train 1 --reuse-local
bash experiments/local_cocu_novel/run.sh eval 1
```

其中第二个参数 `1` 指物理 GPU 编号，可以调整为 `0`、`2` 等。若现有的 Local-CoCu 产物在其他位置，例如此前 `CoCu_Bootstrap_Talk2dino` 实验中，可以通过 `--source-dir ...` 指定其源目录。

## 输出文件

- `outputs/local_cocu_novel/novel_candidates.json`：排除已有 Concepts 后的候选集。
- `outputs/local_cocu_novel/novel_filter_audit.json`：每张图删掉了哪些 Concepts、数量统计。
- `outputs/local_cocu_novel/matched/matched_concepts_detailed.json`：新增 Concept 与最佳 Head 的匹配分数。
- `outputs/local_cocu_novel/train_local_cocu_novel_5plus3.pth`：可直接使用的训练文件。
- `outputs/local_cocu_novel/train_manifest.json`：新增数分布、逐图最终 Concepts。
- `weights/vitb_mlp_infonce_local_cocu_novel_5plus3.pth`：训练所得 Student 权重。
- `output/eval/local_cocu_novel/`：四个分割任务的评估输出。

## 科学实验注意事项

1. **仅判断 Caption 是否已明确提到该 Concept**，包括大小写与常见单复数；不会推理同义词（如 bicycle / bike）。
2. 本方案默认不通过 Head 相似度阈值剔除低分 Concept；继续保留原 Local-CoCu 的 Top-K 排序机制。可选 `--threshold 0.2`，但这属于另一个实验因素，不建议直接混入主对照。
3. 完全复用原版 `extract_candidate_concepts.py`，因此原始 Gallery 的多词短语匹配缺陷仍然存在；本次不同时修改，避免干扰去重的因果对照。
4. 训练沿用原版 Talk2DINO 的 InfoNCE、动态 argmax Head 选择及验证数据；Teacher 的预训练 Projector **仅在训练前筛选 Concept**。
5. 删除已有 Concepts 后不保证每张图片都能选出三个新 Concept。若想强制严格 5+3，增加 `--strict`；不足会报错而不是编造数据。和固定 5+3 进行实验对比时，应报告逐图新增 Caption 数量，并考虑等更新步数对照。
