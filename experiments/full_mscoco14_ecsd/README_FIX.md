# Full MSCOCO14 ECSD caption-count fix

## Root cause

The official COCO2014 caption annotation JSON is not guaranteed to have exactly
five annotation records for every image. Some images have six or more. The old
`build_raw_captions.py` rejected those images, which stopped preprocessing.

## Unified policy

For every image:

1. Validate that at least five non-empty caption annotations exist.
2. Sort annotations by official COCO `annotation id` in ascending order.
3. Keep the first five.
4. Record how many source annotations were present and how many extras were discarded.
5. Use this normalized five-caption Raw set as the only input to ECSD.

This is deterministic and independent of the order of annotation records in
the JSON file. It does not change the ECSD candidate generation, scoring, or
selection algorithm.

## Apply

Unzip this fix ZIP at the Talk2DINO repository root, allowing it to overwrite
`experiments/full_mscoco14_ecsd/build_raw_captions.py` and add
`caption_policy.py`, `validate_caption_contract.py`, and the regression test.

The existing downstream modules (`generate_ecsd.py`, `prepare.py`, and
`evaluate_cisd.py`) already require exactly five captions per image. They
should remain strict: the builder normalizes source data to five, and every
downstream stage verifies that invariant. This prevents six-caption records
from silently entering training.

## Tests

From the Talk2DINO repository root:

```bash
python -m unittest discover -s experiments/full_mscoco14_ecsd/tests -p 'test_caption_policy.py' -v
python -m py_compile experiments/full_mscoco14_ecsd/*.py
```

## Regenerate Raw and ECSD

The Raw JSONs previously generated by the old script must be regenerated:

```bash
rm -f data/coco2014_full/raw_train.json data/coco2014_full/raw_val.json
rm -f data/coco2014_full/ecsd_train.json data/coco2014_full/ecsd_val.json
rm -f outputs/full_mscoco14_ecsd/ecsd_trace_train.jsonl
rm -f outputs/full_mscoco14_ecsd/ecsd_trace_val.jsonl
rm -f outputs/full_mscoco14_ecsd/ecsd_generation_train.json
rm -f outputs/full_mscoco14_ecsd/ecsd_generation_val.json

bash experiments/full_mscoco14_ecsd/run_preprocess.sh
```

If the earlier preprocessing had already assembled Raw/ECSD `.pth` files or
extracted CLIP `ann_feats`, rerunning `run_preprocess.sh` will rebuild the
caption files and assembled datasets. If it reuses existing generated ECSD
JSONs or traces, delete the files above first as shown. Do not reuse ECSD
traces created from the old Raw caption selection policy.

The `raw_manifest.json` now documents the policy and reports the number of
images with extra source annotations and the number of discarded annotations.
